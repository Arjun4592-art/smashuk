# Brand Logos

Logo files live here as SVG wordmarks (auto-generated, brand-colored):

- yonex.svg
- victor.svg
- li-ning.svg
- babolat.svg
- head.svg
- wilson.svg
- k-swiss.svg
- adidas.svg
- bullpadel.svg
- tecnifibre.svg
- dunlop.svg

These are simple text wordmarks in each brand's colour, not official
trademarked artwork (we don't have distribution rights to the real logo
files). If you get official logo assets from the brands directly, just
replace these files with the same names (keep .svg, or add .png and update
the extension in `BrandsBar.tsx`).

If a file is missing, the site automatically falls back to showing the
brand's initials badge (e.g. "YX" for Yonex) — nothing will break.
